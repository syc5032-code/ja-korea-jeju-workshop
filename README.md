## 🛠️ 커스터마이징 가이드

### 1. 외부 구글 폼(Google Forms) / 네이버 폼 바로 연결하기
페이지 자체 모달 대신 기존에 만들어두신 설문지 링크로 바로 연결하고 싶으신 경우:
- `js/app.js` 파일 상단의 `window.EXTERNAL_SURVEY_URL` 변수에 설문지 URL을 입력하세요.
```javascript
// js/app.js
window.EXTERNAL_SURVEY_URL = "https://forms.gle/YOUR_FORM_LINK";
```
*(기본값인 빈 문자열 `""` 상태일 때는 고품격 내장 모달 설문창이 열립니다.)*

### 2. 워크숍 일정 및 장소 변경
- `index.html` 내의 날짜 텍스트(`2026. 10. 15 ~ 10. 17`) 및 장소명(`JW 메리어트 제주 리조트 & 스파`)을 수정하시면 됩니다.
- D-Day 기준 시간은 `js/app.js`의 `targetDate` 변수에서 변경할 수 있습니다.
